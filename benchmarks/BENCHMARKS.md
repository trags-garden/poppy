# Benchmarks

Poppy's retrieval is developed benchmark-led: changes to the default engine,
`bloom`, are decided by measurement rather than by hand.

The measurements run on Rosemary, our memory benchmark harness, which executes
each system's real code under one identical pipeline on public long-term-memory
suites. The methodology and the results will be published with Rosemary, and
this page will carry them once they are.
